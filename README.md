# Moment by Moment

*Drawing closer to God, one moment at a time.*

## This app has moved

**Open Moment by Moment:** https://aa-moment-by-moment.netlify.app

This repository holds an earlier version of the app and is no longer updated. The old GitHub Pages link now sends visitors to the new home.

**Used the earlier version?** Your journal was saved in your browser. Open the old link on the same device, and it will offer to save your journal as a backup file before sending you on. Then, in the new app, open **Settings → Bring in a backup** and choose that file.
